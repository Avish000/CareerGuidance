# Aura AI — Career Guidance & Resume ATS Analyzer

An interactive web application that guides users through **Sign-In**, **Resume Upload & Career Info Input**, **ATS & Skill Analysis**, **Role Percentage Match**, **Career Suggestions**, and a **Step-by-Step Roadmap**.

## Key Features
- **Sign-In & Quick Demo Mode:** Sign in with your details (`Avishkar Bhalshankar` / `avishkar@gmail.com`) or click Instant Demo Sign-In to move directly to Resume & Info.
- **Resume Upload & Info Studio:** Upload resume files (`.txt`, `.md`, `.csv`, or readable `.pdf` text), paste resume text, choose target role, experience level, and roadmap horizon, and add skills with quick-insert chips.
- **Animated Analysis Flow:** Step-by-step progress scanner evaluating skill overlap, resume depth, and role alignment.
- **Percentage Match & ATS Diagnostics:** Visual SVG match ring, verdict badge, matched vs. missing skills, and actionable resume feedback.
- **Career Suggestions:** Explore alternative roles with estimated match scores and switch target roles on the fly.
- **Interactive Roadmap & Persistence:** Check off milestones across phases with automatic `localStorage` persistence and JSON report export.

## Upload to GitHub & Host on GitHub Pages
1. Open your GitHub repository and upload `index.html` and `README.md` to the repository root.
2. Go to **Settings → Pages**, select branch `main` and folder `/ (root)`, and save.
